# Replace Face evidence

Before: the top round of the plate is selected in Replace Face.
After: the same round replaced by the side face beside it; the edge is sharp,
the other rounds, boss and bores are unchanged.

Reproduction: select the round (source) and the side face (target) in
SOLID → MODIFY → Replace Face, then OK. Body closed, 27 faces,
volume 39909.06 mm3.
